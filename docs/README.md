# Cerebro docs

Cerebro builds a wiki from your sources and keeps it current. Agents you write in plain markdown turn your notes, mail, calls and tickets into cited articles, and Claude, Cursor or any MCP client can read them.

## Read these first

1. [Quickstart](quickstart.md): go from nothing to a cited article in ten minutes.
2. [Workspace](workspace.md): what's in the folder, what to commit, and where your keys live.
3. [Sources](sources.md): read from files, GitHub, Slack, Gmail, a calendar, a database or any MCP server.
4. [Agents](agents.md): write the agents that write your wiki.
5. [Runs](runs.md): see when the wiki updates, update it now, and cap what it spends.
6. [MCP](mcp.md): connect Claude, Cursor or a script to your wiki.
7. [Tell](tell.md): tell the wiki something new, ask for a change, and take it back.

## When you need them

- [Command line](cli.md): every command, and how to check answers with evals.
- [Deploy](deploy.md): run a workspace on a server.
- [Templates](templates/README.md): start from a ready-made set of agents, such as [gtm](templates/gtm.md) for a sales team.
- [Apps](apps/README.md): add tools and records to a workspace, such as [Notes](apps/notes.md).
- [Philosophy](philosophy.md): why Cerebro works the way it does.
