# D03: Compact output with a cost

Jo Fen chose eight significant digits for Number printer in release 0.3.0 to keep tutorial output short. The spelling -0 is intentional and preserves the sign when parsed again. Precision round trips were not promised. Mira Vale objected that users might paste output back into the compiler.
